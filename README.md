# 📊 Student Time Distribution Chart

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg?logo=python)
![Matplotlib](https://img.shields.io/badge/Matplotlib-3.x-green.svg?logo=plotly)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

This project visualizes how a student spends time over a week using a **stacked area chart** built with [Matplotlib](https://matplotlib.org/).  
The chart shows daily time allocation for **studying, playing, watching TV, and sleeping**.

--- ggggg

## ✨ Key Features
- 🎨 **Color-coded stacked area chart** for activities.
- 📅 **7-day timeline** for easy visualization.
- 🖥 **Simple Python code** – beginner-friendly.
- ⚡ **Lightweight project** with minimal dependencies.
